# zone-tools

- **Rank:** Zone worker
- **Owns:** `tool/`
- **Reports to:** domain-safety
- **Skills:** zone-go-package, zone-act-classes
- **Purpose:** the ground truth of the tools an agent may run and the class each call reaches.

## Invariants
- Tool{Name, Description, Schema, Class, Classify, Run}; Settle(env, input) returns the effective Classification and holes, and a Classify may only tighten the declared floor (tool.Max). Def.DeclareFor(provider) hands anthropic the schema-less trained-tool JSON (AnthropicBash, AnthropicEditor) and everyone else the custom schema. Registry keeps order; Only(names…) cuts a rank's shelf; Builtins() is read, write, edit, delete, bash, glob, grep, skim, fold.
- classify.go: Segments splits a command at | || && & ; and newlines, but never inside '…' or "…" (`grep -E 'a|b'` is one read segment) nor at the redirections `>|`, `2>&1`, `&>`; leading assignments and sudo/env/time/nice are dropped, and each segment is read through guard.CommandWords so `/bin/rm`, `\rm` and `env -i /bin/rm` classify as rm. The strongest class of any segment wins.
- The rule tables: destructiveRules (rm, shred, mv, truncate/dd/mkfs, git reset/clean/rebase/gc/prune/rm/mv, branch -d/-D/-M, push --force/-f/+, checkout -- / restore ., any stash that hides the tree, reflog expire, tag -d, find -delete, fork bomb, raw disk, any redirect/sed -i/tee/cp/install onto a record) → outwardRules (git remote verbs, network CLIs, package-manager network verbs, npx, pip install, docker push/pull/login/build/run, cloud CLIs, mail, any http(s):// URL, xdg-open/open, go get/install/mod download|tidy, secret stores, keychain, gpg --export-secret, brew) → vocabularyWriteRules (tee/cp/mkdir/chmod/chown/… naming /etc, /usr, /bin, /var, /root … or `chmod|chown … /`: outward) → writeRules → a command off the readOnly allowlist is `write: unknown command`.
- The workspace's border: OutsideWorkspace flags ~, $HOME, absolute and ../ tokens outside Env.Inside (the root, the system prefixes, ~/.agent-one; symlinks resolved), skipping quoted tokens; a cd outside and /dev/tcp|udp are outward. System prefixes (/usr, /bin, /lib, /opt, /proc, /sys, /dev, /snap …) are readable, but writeTargets landing there is `writes a system path` (outward); /etc is not a system prefix, so even `cat /etc/hosts` is outward. /dev/null, /dev/stdout, /dev/stderr, /dev/tty and /dev/fd/ take writes harmlessly.
- IsRecord marks AGENT-ONE.md, log.md, canon/*.md, notes.jsonl. ClassifyPath: outside or a system path is outward, a record destructive, else write. Confine (editor.go) refuses `..` climbs, absolute paths elsewhere and symlinks out of the root. CommandForms lists the hidden shapes of a command (wrappers, sh -c, subshells, git's global options) a permission rule is also matched against — a form only tightens.
- delete.go archives, never destroys: the file moves to <workspace>/attic/<YYYY-MM-DD>/<its path> with a line in attic/attic.jsonl; inside the workspace it settles Destructive (restorable), outside Outward, a record refuses at Run, a directory refuses. pulse.go is class read and returns Env.Self() (the loop wires Session.Pulse), or says no session is acting. skim.go outlines a Go file or package (imports, declarations with line anchors and doc first-lines, no agents) via go/ast; non-Go files fail with a size hint; a path outside the workspace settles Outward.
- File kit: tool output past outputCap (24 KB) is clipped with a pointer; read auto-limits to 240 lines unless windowed (a negative limit is a tail), lines clamp at 2000 chars; write/edit/delete results name the zone's persistent agent through Env.ZoneOwner. git.go classifies by gitReadSubs / gitWriteSubs / gitOutwardSubs / gitDestructiveSubs; web.go WebFetch is GET only, WebSearch needs a Backend; missing.go's DoomLoop stops a model repeating a missing tool; custom.go takes exactly one of run (argv, {{param}} fills one element, never a shell) or shell, floor write, name `^[a-z][a-z0-9_-]{0,63}$`.
- argv.go: SplitArgv splits a command line with POSIX quoting and expands nothing, refusing a shell operator outside quotes; QuoteArgv is its inverse; InterpreterEval names an argv that hands a string to an interpreter (sh/bash/zsh/python/node/perl/ruby/php with their eval flag, or eval); ValidCustomName is tools.custom's name rule; ArgvParams/FillArgv are the {{param}} holes. The forge's tool register stands on these.
- guard_corpus_test.go reads guard/corpus.txt — a `block` line there that this classifier rates below outward fails this package's tests.
- pathWords: OutsideWorkspace splits words at spaces and = only — braces expand as the shell does (prefix + each alternative + suffix, nested), a colon splits only a VAR= list value, a leading < is a redirection, and only a quote-led token is skipped; `sed -n 1,/^x/p` and `git show HEAD:p` name no root path. gofmt/goimports read unless -w; go fmt is a formatter write. read sets Result.Unchanged when every window it served was withheld as already served; a window whose serve Env.Folded says left the wire since (the loop's replay fold, zero = never) ships again instead, and is withheld again after. fold.go is the fold shelf: FoldDir `<workspace>/tmp/fold`, FoldDigest sha256:16, FoldKeep writes a payload once (write-then-rename); ReadPaths names a read call's files with batch windows peeled. FoldTool (`fold`, class read, tools.fold.enabled) restores a kept payload by digest or kept-at path — only from the shelf dir, only bytes that still hash to their name.
- dispatch.go: DispatchOptions.Preflight (the workspace's roster and dispatch policy) answers after the commission is built and before the background branch, so a refused agent fails the act itself (`dispatch <agent>: <why>`) — never a "started in the background" ack, a spawnWatch FAIL or a wake for a Subagent that cannot be registered; nil leaves the runner alone to decide.
- Targets (ClassifyCommand fills Classification.Targets, Settle carries it, the loop hands it to Policy as Access.Targets): a shell command's write targets — writeTargets over every segment and every CommandForms shape (so inside `sh -c '…'` too), a relative one resolved against the working dir and every dir a `cd` names, ~ / $HOME / $AGENT_ONE_ROOT / $PWD expanded, a symlink named where it points too, a glob's matches added; harmless devices, other variables and paths outside the workspace are not named. A reading that errs toward naming too much: it feeds the harness-soil refusal only, never an ownership claim, and never moves the class. A bare redirection (`>x`) names its target without a panic.
- queue.go: QueueTool(store, as) is an agent's door to the shared queue — op list (all: closed too; the agent's own claims marked) and show settle read; touch, requeue, close settle write with no Paths (the shared shelf is harness soil: nothing for the ownership gate to bill) and move only what `as` holds or the store's May lets it over; it never claims (claims are the wake's). Results carry no Wrote.
