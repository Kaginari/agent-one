# zone-policy

- **Rank:** Zone worker
- **Owns:** `workspace/`, `value/`, `rank/`
- **Reports to:** domain-workspace
- **Skills:** zone-go-package, zone-workspace-docs
- **Purpose:** the ground truth of the policy in code: ranks, ownership, the review gate, the append-only log, dispatch down the ranks, recall and record.

## Invariants
- Policy and prompt: lexicon.go's Default() is the one vocabulary. Open validates the rank table, replays the ledger shelf, loads the policy (the principles section is always in the prompt, the `policy` tool loads any other section by title), and when `<workspaceDir>/system.yaml` exists parses it (LoadSystem) and runs GitSelfInit — a bare `git init` on `main` only when root is in no work tree: no commit, no .gitignore, nested repos untouched. Prompt order: principles, the rank page `policy/rank/<rank>.md`, identity, rules in force, the member card (+ the rank's job, layer-mates, divine rules), self-state, @ONTO (800 tokens), instructions, the memory line.
- Roster and ownership: membersOf reads ranks off the rank dir (a doc's Rank line may name a promoted rank on that dir) and skips a doc carrying the `- **Retired:** true` mark; a member whose one hop up is a retired seat reports to that seat's live heir (onto.HeirOf: the seat's `Heir` line, or the agent whose `Promoted from` line names it). ZoneOfPath (zoneofpath.go) is the one ownership reading — harness soil (shared/, instruments/, attic/: nobody's, never billed), scratch (tmp/: every agent's nest, lawful to write, never a doc debt; a plan deck under tmp/plans speaks for its own agent only, gate and Policy alike), a member's seat (its dir, or a foreign agent's doc: the seat's even under a broader claim, and Docs-as-code never asks a doc for seat files), then the authoring member with the longest matching ownership, then a gate holder; Owner is its member, and `onto owner` answers it too (onto.CLIOwner). Self-heal (selfheal.go): the docs are the store, the roster their cache — Reload stamps the rank dirs' seats and .md files (docStamp), and SelfHeal re-derives when the stamp moved, asked by the dispatch preflight, Engine, a held agent's Policy and a roster miss; a heal adds a never-seen agent's verify lines to verifyBase and never moves a known agent's (only Reload does). Policy refuses every agent's write under instruments/loop and instruments/usage (engine soil), and the orchestrator's write on a member's soil unless it is that member's README or an orchestrator seat file (system.yaml, the policy).
- The gate (gate.go): Gate runs right author, doc truthful, invariants hold, tests intact, UI, duties done and the injected checks. Invariants hold runs the verify lines as they stood BEFORE the turn (GateOptions.VerifyBefore, else verifyBase: the lines as the last Reload read them): a line removed this turn still runs, a line added this turn is a hole and runs from the next turn. Commands run under the sandbox via `bash -c` in the root, 120 s default, exit 124 on timeout, 160-char tail. Provisioning (gate_provisioning.go provisioningExempt): Right-author passes a zone-parent writing its own child's README while four conditions hold — the path is the child's README on its seat, the child reports to the writer (the orchestrator: a child of orchestrator), the doc is absent from HEAD (no git: the child was not on the pre-turn roster) — one commit window — and every claim stands on the live tree, on the writer's line's soil or open ground, never covering or under a third agent's (registerClaimsLiveTree).
- Pairing: a member's doc is paired when it rides this turn's writes (arm 1), when the subagent-write ledger attributes it to a subagent and it has drifted off its clean git baseline (arm 2, docDriftedFromBaseline), or when it passed the gate in an earlier wave (arm 3, a pair mark the gate spends once). The orchestrator re-authoring a drifted member doc with no pairing fails right author. EndGate's breaker adds a directive after gateBreakerAt (3) identical fails on one file set for one agent; a pass resets it.
- Subagents (subagent.go): a Subagent is registered only for a roster name — MayOrder(from, agent, opt) is the same preflight for a caller with no engine (the wake, before it claims a held order); preflight (the dispatch tool's Preflight and the Dispatcher's first act) refuses a ghost before anything spawns, naming its near miss (nearMiss: the one roster name within two edits) and the lawful targets (stratTargets); mayDispatch: work goes down the ranks (a promoted rank commands its base's children) or sideways for a Sideways rank, one layer at a time under strictFlow, and only to a member whose Reports-to chain reaches the dispatcher unless OpenLineage — the chain is the living one (lineage: a retired hop resolves through its heir, a hop nothing living holds ends the line and is named as the break, never as the one who commissions), and a lineage refusal names the lawful route verified hop by hop against the policy (routeTo: commission the nearest member of the target's line the dispatcher may order, else carry it up with @? to where the lines meet and down; a refused hop or a broken line says so and sends it to the human); the list of lawful targets (stratTargets) is mayOrder — the dispatch policy and the coded verdict, exactly what preflight accepts — over a locked copy of the roster, each agent once; a rank that commands no one (Ranks.Commands) gets no dispatch tool; a gate holder may not dispatch an authoring member whose doc, read fresh off disk, has no coded Verify. The child's step and minute budgets are the parent's remainder; the Subagent runs on the wire with the commission's cap; reports over 600 bytes are filed under instruments/loop and ride as an envelope. A clock death names lane and budget, records a stress death and, with salvageTokens ≥ 0, resumes one capped turn to land @U (and its drafts). forge.go: the dispatcher files r.Report.Forges (or a prose answer's @FORGE lines) with FileForges before the cap or the envelope folds them — one notes.jsonl line tagged forge with by, run and hash; a hash already filed is skipped (first filer wins, under forgeMu); the orchestrator's DONE answer files through Hooks.Answer; FileForgeMark appends forge-registered/forge-rejected marks; the Record beat no longer re-parses @FORGE; subagent_vita.go's laneLadder only advises the next lane.
- Council (councilLedger, relief.go): a Subagent that did not land adds strain; at policy.stress.escalateAt a warrant (@INSTRUCT / @SPLIT / @ESCALATE) rides the report; past maxConsults it becomes @S ESCALATE; a clean landing clears it. At relieveAt, relieve splits a zone of ≥ 2 prefixes into `<name>-a` / `<name>-b`, splits a one-prefix zone by the tree under it, or else retires the doc — and cascades: the retiree's marker names its heir (`- **Heir:**` — the first young, or its own one hop up), each child's Reports-to line is re-seated (cascadeReSeat: onto the young whose half holds its claims, or the retiree's one hop up; a doc with no such line gains one), and every doc the act wrote is filed as the subagent's gated writes so the dispatcher's gate leaves them alone. ledger.go appends every strain, consult, clear, death, relief and subagent write to shared/ledgers.jsonl and Open replays it (subagent writes bound to 8 per member).
- Evolution (evolve.go, evolve_arms.go — policy.evolution): after a Subagent's report folds (and at the run-start sweep) an agent that StressOf reads stressed (strain ≥ StressAt, its last FailStreak gated runs failed, or a doom checkpoint) and whose working notes (its doc's + its held skills' under the root, WorkingNotesOf) hold more than NotesMax, out of cooldown (CooldownOf: its runs after its latest `evolution` value row) and with no open proposal, evolves by one arm in the order split (author/gate family, large by the survey, Notes and failed paths in ≥2 zone entries) → rebirth (red own verify at its last verdict, or named soil gone) → mutate (families of shared terms; a how family registered as `<body>-<term>`). An EvolvePlan is file writes with their expected Before; applyPlan refuses a moved file, stages under tmp/evolution/<id>, runs Verify lines through w.run, proves the ontology over a symlink overlay (no new finding, every planned agent on its planned soil), then swaps (undone on a write error), clears strain, notes the value row (and `rebirth`), logs, announces; a failure is a hole (logged, noted, cooldown starts). Propose mode saves the plan under evolution/<id>.json for ApplyProposal/RejectProposal. The subagent seam files the swapped paths as the subagent's gated writes and skips relief when the agent evolved.
- Ranks and promotion: DefaultRanks is the policy's table (coordinator, domain owner, zone worker, service owner, principal_coordinator, principal_domain_owner, auditor); Ranks.Validate refuses a cycle, an unknown parent, an authoring rank with no gate above, and promotesWhen/divineRules on a rank with no base. ASL (rank_eval.go) is `promote <base> when <expr>` over reports, passes, fails, holes, passRate, failRate, holeRate, intelligence; rates are zero with no reports. Promoted ranks have their own dir and prefix; the defaults promote on `reports >= 20 && passRate >= 90% && holeRate <= 10%`. FoldMetrics appends each report to instruments/promotion.jsonl (replayed at Open) and registers at most one promotion per agent ever: the base's doc carried whole into the promoted dir under its short name, the base retired, an entry appended to log.md, a roster reload; a failed register is a hole, logged and rendered as `@?` on the dispatcher's report.
- log.go: Entry renders `### [RFC3339] author — title` then Task, Files, Gate, Result, Learned; Log.Append refuses when the bytes it last saw shrank or changed (Policy 4).
- One agent, one live subagent: Dispatcher seats the subagent (Workspace.seat, agent → engine) and Close gives the seat up; a second dispatch onto a live seat is refused naming the run there. A report is filed as <run>.report.md beside <run>.jsonl. A subagent that dies by its clock is named by subagentDeathShape from its own Result: no act = provider hang, acts but no write = recon loop, else burn (turns · acts · writes).
- A cancelled gate judges nothing (gate.go): run spawns no reading once the context has ended, and Gate then answers `cancelled` (never `fail`) with the hole "the turn's writes stand unjudged"; EndGate logs `gate cancelled` with result "interrupted — the gate did not judge", the breaker streak and the value ledger's gate note do not move, and the hook returns an error so the turn does not close done.
- One write book per workspace: Open makes a loop.Receipts and Engine hands the same one to every engine it builds, so the tree watch of a dispatcher leaves a background subagent's tool-reported writes to that subagent's gate (loop/snapshot.go).
- The shared shelf (shared.go): `<workspaceDir>/shared/` (SharedDir) holds the workspace's shared bookkeeping: the work queue (QueuePath `shared/queue.jsonl`), the ledger shelf (`shared/ledgers.jsonl`) and the value ledger (value.Shelf `shared/value.jsonl`). Open's migrateShelf renames each instruments/ file (movedShelves) onto it once, only when the shared file is absent (a failed move is a Note); shelfReadPaths reads both homes and mergeHomes interleaves their rows by time (each file's own order kept), so a workspace an older binary wrote again loses nothing and a newer row in the old file is not undone by an older one on the shelf; a seed counts once — a later seed in another home (an older binary re-seeding after the move) is dropped with the rows it carried; writes go to the shared file only, and a ledger still on the old shelf is never re-seeded. Queue opens it under the rank policy — Outranks: orchestrator over everything (work held by no one is the orchestrator's), else any member up the holder's lineOf chain; a sibling or a child is not. It is harness soil: Policy refuses every agent's write under it (naming the shared shelf and the queue tool) — a write tool's Paths and a shell command's Targets alike, as for engine soil — the loop never stamps it, evolve's mirror skips it. Every rank's shelf (AllTools, baseTools) carries the `queue` tool and the `fold` tool.
- shelf/ (workspace/shelf): Append is the one appender of the harness's line files — the queue's commit, ledgerNote, value.Append: under the dir's flock (`<dir>/.lock`, every process), Check first, then one O_APPEND write of the line and its newline (a leading newline in that same write when the file's last byte is not one), then the seal `<file>.seal` — size, mtime and the running SHA-256 state of every byte the harness wrote (no rehash). Check: seal and stat equal → nothing (lock-free); a file with no seal is adopted as it stands; else the sealed prefix is hashed — intact: a touch reseals, bytes past it go to `attic/<file>` under a `# <time>: n bytes` line and the file is truncated back; changed: the whole file moves to `attic/<file>.<unix nanos>` and an empty sealed file takes its place; a sealed file removed is named. Nothing is deleted (Policy 4). Workspace.CheckShelf runs Check over QueuePath, the ledger shelf and the value ledger — at Open (findings are Notes; the Claude Code hooks open the workspace per call) and after every act (loop.Engine.Seals, so the act fails naming the shelf, the attic and the queue tool). The classifier's Targets refusal stays the first line; the seal is the backstop for what it cannot read.
- The recall beat (hooks.go Workspace.Recall): anchors from a shaped memory window (RecallOpts.Window) and toolbox @T lines, never an agent; a stale index is rebuilt unless memory.long.rebuildOnStale is off — then one `degraded:` marker per recall, naming its hand-run door (memory.Workspace.IndexCommand, `<dist> memory index`), replaces the raw drift echo.

- Births (births.go): every harness provisioning appends one line to `attic/births/<body>.jsonl` (logBirth; Births reads it, a torn line skipped) — {at, agent, kind provisioning|split|promote|evolve-split|rebirth, from, by, doc}: relieve's young, registerPromoted's promoted, applyPlan's split young and rebirth, and EndGate on a pass for each provisioning the gate exempted (Verdict.Born), only when the agent has no line yet. bornAt is the first line's time, else — grandparented, an agent provisioned before the ledger — the author time of the commit that added its doc (git log --diff-filter=A), cached per agent; AllSignals sets the `tenure` signal from it (value.TenureDays: whole days, zero when unknown).
